# AI Resume Analyzer

An AI-powered Resume Analyzer built using Django and Groq API.

## Features
- Upload PDF resume
- AI analyzes resume
- Resume score generation
- Strengths and weaknesses detection
- Missing skills suggestions
- Beautiful UI with Bootstrap

## Technologies Used
- Python
- Django
- Groq API
- HTML/CSS
- Bootstrap

## Run Project

```bash
pip install -r requirements.txt
python manage.py runserver
